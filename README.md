# 🎯 Ruleta de Pausa Activa • CTE

Aplicación interactiva diseñada para dinamizar sesiones de Consejo Técnico Escolar (CTE), clases y reuniones docentes mediante pausas activas divertidas, ejercicios de respiración, dinámicas motrices y actividades de integración.

## 🚀 Demo en línea (GitHub Pages)

Puedes acceder a la aplicación directamente desde:
👉 **[https://felipesalle.github.io/pausaactiva/](https://felipesalle.github.io/pausaactiva/)**

---

## ✨ Características

- 🎲 **Ruleta interactiva animada**: Giro suave con efectos de sonido y animación física realista.
- 🧘 **Diversas categorías de pausas activas**:
  - Estiramiento y movilidad
  - Respiración y relajación consciente
  - Desafíos motrices y coordinación
  - Dinámicas rápidas de integración
- ⏱️ **Temporizador integrado**: Cuenta regresiva para cada actividad con alertas sonoras.
- 📱 **Diseño responsivo**: Adaptado para proyectores escolares, pantallas interactivas, tablets y teléfonos móviles.
- ⚡ **Autónomo y rápido**: Funciona sin dependencias externas complejas.
